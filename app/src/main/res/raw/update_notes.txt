IdleSkull 0.2.0-beta

• App 图标改为带红色警示元素的海盗旗骷髅，并为系统深浅色环境提供不同配色。
• 首页大骷髅背景重新设计：浅色模式使用深色骷髅与暗红裂痕，深色模式使用骨白骷髅与亮红眼窝。
• 首页模式选择器与下拉面板保持等宽，继续使用单一“正计时 / 倒计时”入口。
• 倒计时输入弹窗统一为像素几何边框，并保持“时 / 分 / 秒”等宽布局。
• 新增应用内像素文字渲染组件：标题、计时数字、按钮和关键数据使用无抗锯齿像素化文字，长说明文字继续优先保证可读性。
• 按钮、卡片、弹窗和模式选择器改用阶梯切角的像素几何外形。
• 首页、设置页和统计页补齐小屏滚动处理，统计页各范围在内容超出时可独立滚动。
• 设置页移除 Demo 阶段的临时说明和演示数据入口，只保留外观、更新、数据与版本信息。
• 版本命名调整为 X.Y.Z-beta；更新判断继续仅依据递增的 versionCode，确保 Beta 与正式版均可正常升级。
• Beta 更新清单改为读取 main 分支的 latest.json，因此 GitHub Release 即使标记为 Pre-release 也能正常被检查到。
