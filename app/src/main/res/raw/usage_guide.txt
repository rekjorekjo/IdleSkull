IdleSkull 使用说明

卷与摆
• 首页提供“开摆！”和“开卷！”两个并列按钮，两者互斥；一次只能进行一种计时。
• “开卷”每 1 秒对当前等级骷髅造成 1 HP 伤害；“开摆”每 1 秒恢复 1 HP，最多回到当前等级满血。
• 骷髅 HP 归零后立即进入下一级；摆烂不会让已经击败的等级倒退。
• 当前 0.3.0 Beta 为了快速测试动画，源码临时保持 `BASE_HP = 60L`，因此 Lv.1 = 60 HP；Lv.2 起仍按 `BASE_HP × π × ln(n)` 计算，再向下取整到 1000 的倍数且不低于 BASE_HP。

计时
• 首页默认使用正计时；点击模式选择器可切换正计时或倒计时。
• 倒计时可以输入时、分、秒；选择完成后再点击“开摆！”或“开卷！”。
• 计时中可暂停、继续或结束；当前计时结束前不能切换正计时 / 倒计时，也不能在摆与卷之间切换。
• HP 不会每秒写入磁盘，而是按照有效计时区间计算；暂停时间不计入，App 被系统回收后重新打开仍可继续正确结算。
• 一整段卷 / 摆少于 1 分钟时视为误触：结束后不生成日志、不计入统计，同时撤销该段临时显示的伤害 / 回血。

首页
• 首页不再显示“今天你卷还是摆？”标题，顶部只显示“今天 摆 … · 卷 …”。
• 首页骷髅区按“血条 → `HP: 当前/最大` → 骷髅图片 → 中文名（EASY/MEDIUM/HARD/INSANE/BOSS） Lv.x”排列。具体 HP 数字约每秒刷新，血条与眼部强度约每 5 秒刷新。
• 不再显示“本次已击破 x 个骷髅”文字提示。
• 深色模式使用红色眼光，浅色模式使用高亮阴森绿眼；当前 HP 越高，眼窝光效越强。8 个主题的眼光位置分别按实际图片眼窝校准，图片缩放后仍保持相对位置。眼光不再做常驻呼吸脉冲。
• 开卷会让光效随着 HP 下降而减弱；摆烂会让光效随着回血重新增强。
• 主计时数字与具体 HP 数值每秒刷新；血条与眼部强度约每 5 秒刷新，顶部“今天 摆 / 卷”汇总约每 10 秒刷新；空闲和暂停时停止秒级轮询。

击败动画
• 骷髅被打空血时会播放一次全屏击败动画，计时本身不会因为动画暂停；动画遮住画面期间，新等级骷髅仍会继续被扣血。
• 动画开始时会先隐藏首页原本的骷髅图片与眼光，但保留原布局占位；随后由击败动画中的骷髅从下方冲到屏幕中央并放大，避免两个骷髅同时叠在画面里，再直接进入主题光爆。
• 黑 / 白全屏扩散和泼墨均已移除；随后直接播放浅色绿色 / 深色红色的光爆，约 3.9 秒从中央扩散到屏幕四角，由径向渐变、柔光晕、亮环、放射光束和发光火星组成。
• 爆发结束后才重新出现裂纹骷髅；裂纹由 Compose Canvas 实时绘制，不是单独的静态图片。裂纹会在约 0.5 秒内从主裂缝向分支动态生长，并统一使用灰黑色 / 深灰色，不再跟随红光或绿光。`DEFEATED` 固定从单词最左侧的 D 开始，后续字母向右逐个重击出现。
• `DEFEATED` 后显示升级：旧等级 → 下一等级，并显示下一等级 HP。跨主题 Boss 会显示“XXX骷髅 Boss 已被击败”，随后进入下一主题的 E 档。

骷髅主题与难度
• 首批共 40 级，每种骷髅连续出现 5 级，难度依次为 E / M / H / I / B（Easy / Medium / Hard / Insane / Boss）。
• Lv.1–5 宝宝骷髅；Lv.6–10 小丑骷髅；Lv.11–15 舞王骷髅；Lv.16–20 厨子骷髅；Lv.21–25 武士骷髅；Lv.26–30 海盗骷髅；Lv.31–35 蛇王骷髅；Lv.36–40 恶魔骷髅。
• E/M/H/I/B 只改变文字与等级，不额外生产五张图片；每个主题只使用一张完整 PNG。
• Lv.40 暂时继续普通击败 / 升级流程，不设置最终关卡结算。

日志
• 页面标题为“日志”。摆 / 卷选择器位于右上角，点击后以紧凑下拉菜单切换。
• 下方继续使用“日 / 周 / 月 / 年”四段选择器，四个时间范围各自记住上一次浏览位置。
• 日 / 周：点击中间日期打开主题化像素日历。
• 月：点击中间月份，在等宽的“年 / 月”输入框中输入目标月份。
• 年：点击中间年份直接输入目标年份。
• 日视图长按某条记录可以改名；空名称会保存为“未命名”。
• 单条记录显示类型、起止时间和右对齐时长。

导出与分享
• 导出入口位于“设置 → 数据 → 导出记录”。
• 可以分别选择摆 / 卷、日 / 周 / 月 / 年、目标日期以及黑白 / 彩色样式。
• 日视图导出高度会根据记录数量动态增长，不会因为一天记录较多而截断。
• 导出完成后直接打开 Android 系统分享面板。

桌面小组件
• 小组件继续支持开始、暂停、继续与结束，并与 App 共用同一份 ActiveTimer。
• 0.3.0 首版中，小组件从空闲状态开始时默认创建“摆”记录；“卷”请先在 App 首页开始。
• 如果 App 已经处于“卷”计时，小组件仍可正常暂停、继续与结束。
• 运行中的时间由系统 Chronometer 秒级刷新，避免 App 每秒重建 RemoteViews。

主题与数据
• 设置页支持浅色与深色模式。
• 0.3.0 不迁移旧骷髅血量进度；当前测试源码直接按 BASE_HP = 60L 的规则从 Lv.1 开始。
• 0.3.0-beta 使用新的 0.3 数据结构，Beta 阶段不保证兼容旧测试数据。
• Debug 版本只在统计层叠加内存测试样本；Release 不包含测试记录，也不会污染真实骷髅进度。

应用更新
• 更新机制继续参考 The Day：优先读取固定 latest.json，请求失败时仅使用 GitHub latest Release API 做一次兜底。
• 发现新版本后由用户主动点击“下载并安装”；APK 使用 Android DownloadManager 下载。
• 下载完成后校验文件大小与 SHA-256，最终由 Android 系统安装程序确认安装。
• Beta tag 可以保留 `-beta`，但 GitHub Release 本身不要勾选“Set as a pre-release”，否则 GitHub latest 路径会忽略它。

• 设置页“清空数据”会清空日志、终止当前计时，并把骷髅等级 / HP 重置到 Lv.1 满血。
