IdleSkull 使用说明

卷与摆
• 首页提供“开摆！”和“开卷！”两个并列按钮，两者互斥；一次只能进行一种计时。
• “开卷”每 1 秒对当前等级骷髅造成 1 HP 伤害；“开摆”每 1 秒恢复 1 HP，最多回到当前等级满血。
• 骷髅 HP 归零后立即进入下一级；等级越高最大 HP 越高。摆烂不会让已经击破的等级倒退。
• Lv.1 当前为 1800 HP，每升一级增加 450 HP。

计时
• 首页默认使用正计时；点击模式选择器可切换正计时或倒计时。
• 倒计时可以输入时、分、秒；选择完成后再点击“开摆！”或“开卷！”。
• 计时中可暂停、继续或结束；当前计时结束前不能切换正计时 / 倒计时，也不能在摆与卷之间切换。
• HP 不会每秒写入磁盘，而是按照有效计时区间计算；暂停时间不计入，App 被系统回收后重新打开仍可继续正确结算。

首页
• 顶部同时显示“今天 摆 … · 卷 …”。
• 骷髅区域显示 `SKULL Lv.x`、血条以及 `当前 HP / 最大 HP`，例如 `6000 / 10000`。
• 深色模式使用红色眼光，浅色模式使用高亮阴森绿眼；当前 HP 越高，眼窝光效越强。
• 开卷会让光效随着 HP 下降而减弱；摆烂会让光效随着回血重新增强。

时间记录
• 日志页标题为“时间记录”。顶部先选择“摆 / 卷”，再选择“日 / 周 / 月 / 年”。
• 四个时间范围各自记住上一次浏览位置。
• 日 / 周：点击中间日期打开主题化像素日历。
• 月：点击中间月份，在等宽的“年 / 月”输入框中输入目标月份。
• 年：点击中间年份直接输入目标年份。
• 日视图长按某条记录可以改名；空名称会保存为“未命名”。
• 单条记录显示类型、起止时间和右对齐时长。

导出与分享
• 导出入口位于“设置 → 数据 → 导出记录”。
• 可以分别选择摆 / 卷、日 / 周 / 月 / 年、目标日期以及黑白 / 彩色样式。
• 日视图导出高度会根据记录数量动态增长，不会因为一天记录较多而截断。
• 导出完成后直接打开 Android 系统分享面板。

桌面小组件
• 小组件继续支持开始、暂停、继续与结束，并与 App 共用同一份 ActiveTimer。
• 0.3.0 首版中，小组件从空闲状态开始时默认创建“摆”记录；“卷”请先在 App 首页开始。
• 如果 App 已经处于“卷”计时，小组件仍可正常暂停、继续与结束。
• 运行中的时间由系统 Chronometer 秒级刷新，避免 App 每秒重建 RemoteViews。

主题与数据
• 设置页支持浅色与深色模式。
• 0.3.0-beta 使用新的 0.3 记录数据结构，不迁移 0.2.x Beta 的旧计时记录。
• Debug 版本只在统计层叠加内存测试样本；Release 不包含测试记录，也不会污染真实骷髅进度。

应用更新
• 更新机制继续参考 The Day：优先读取固定 latest.json，请求失败时仅使用 GitHub latest Release API 做一次兜底。
• 发现新版本后由用户主动点击“下载并安装”；APK 使用 Android DownloadManager 下载。
• 下载完成后校验文件大小与 SHA-256，最终由 Android 系统安装程序确认安装。
• Beta tag 可以保留 `-beta`，但 GitHub Release 本身不要勾选“Set as a pre-release”，否则 GitHub latest 路径会忽略它。
